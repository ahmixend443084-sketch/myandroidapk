YALLA QUICK SEND - APK build without a laptop

Important: This project is still a prototype. The APK build does not mean that Yalla's SEND button or auto-send features are guaranteed to work. Test carefully. Accessibility permission can read screen content while enabled; only enable it if you accept that.

Build using GitHub Actions (a laptop is not required, but a GitHub account is):
1. Create a new repository on GitHub. Keep it private if you prefer.
2. Upload all files and folders from this ZIP into the repository root. Make sure .github/workflows/build-apk.yml is uploaded too.
3. Commit the files to the main branch.
4. Open the repository's Actions tab. Select "Build Yalla Quick Send APK" and tap "Run workflow" if it has not started automatically.
5. Wait for the run to finish successfully. Open that run and download the artifact named "Yalla-Quick-Send-debug-apk".
6. Extract the downloaded artifact ZIP. It contains app-debug.apk. Install it on your phone.

If the build fails, send a screenshot of the red error/log. Do not download random APK files from third-party sites.
